# OS별 개발 환경 설정 안내

새 PC 설정은 사용하는 OS 경로 하나를 선택해 진행합니다. Intel Mac은 Apple Silicon Mac과 도구 지원 조건이 달라 별도 문서를 사용합니다. Setup은 설치 순서·PATH·설치 확인을, Tools는 도구별 상세 사용·업데이트·복귀를 안내합니다.

| 환경 | 설정 문서 |
| :--- | :--- |
| Windows 11 x64 | [Windows 설정](./Windows_Dev_Setting.md) |
| macOS Apple Silicon | [Apple Silicon 설정](./macOS_Dev_Setting.md) |
| macOS Intel | [Intel 설정](./macOS_Intel_Dev_Setting.md) |

새 터미널에서 설치한 도구의 버전·경로를 확인합니다. 프로젝트별 SDK·런타임은 해당 저장소 설정으로 선택하며, 설치 확인은 프로젝트 빌드 성공을 뜻하지 않습니다. 새 프로젝트는 [보일러플레이트 시작 가이드](../02.Boilerplates/README.md)를 진행합니다.
