# OS별 개발 환경 설정 안내

새 PC를 설정할 때 OS에 맞는 한 문서를 순서대로 진행합니다. Setup에는 빠른 설치·PATH·확인 명령이 있고, Tools에는 자세한 사용·업데이트·복귀 절차가 있습니다.

| 사용하는 환경 | 시작 문서 |
| :--- | :--- |
| macOS | [개발 환경 설정](./macOS_Dev_Setting.md#cpu별-확인-사항) |
| Windows | [Windows 설정](./Windows_Dev_Setting.md) |
| Ubuntu / Debian | [Linux 설정](./Linux_Dev_Setting.md) |

## 완료

새 터미널에서 선택한 도구의 버전·경로를 확인합니다. 프로젝트별 SDK·런타임은 해당 저장소 설정으로 선택합니다. 설치 확인은 프로젝트 실행·빌드 성공을 뜻하지 않습니다. 새 프로젝트는 [보일러플레이트 시작 가이드](../02.Boilerplates/README.md#처음-실행하는-순서)를 진행합니다.
