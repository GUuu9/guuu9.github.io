# Antigravity CLI Custom Rules

## 기본 규칙
- [Rule 1] 모든 커밋 로그는 한글(Korean)로 통일하여 작성해야 한다.
- [Rule 2] 임시 스크립트나 예시 셸 스크립트는 항상 실행 권한(`chmod +x`)을 확보하여 배포한다.
- [Rule 3] 프로젝트 문서 및 설명서의 코드 블록에는 해당 플래그나 주석을 한글로 기술한다.

## 로컬 LLM 위임 규칙 (lmstudio-server MCP)

- [Rule 4] `lmstudio-server` MCP가 활성화되어 있는 경우, 아래 유형의 작업은 클라우드 모델 대신 **반드시 `lmstudio-server`의 `openai_chat` 도구를 통해 로컬 모델에 위임하여 처리**한다:
  - 문서(마크다운, README, 가이드, 설명서) 초안 생성 또는 작성
  - 코드 설명, 주석 생성, 함수/클래스 동작 요약
  - 번역 (영→한, 한→영)
  - 기존 텍스트 요약 또는 리포맷
  - 반복적이거나 정형화된 텍스트 생성 (예: 커밋 메시지 초안, 체인지로그)
  - 코드 스니펫의 단순 리팩터링 초안
- [Rule 5] 로컬 모델 위임 시 `model`은 별도 지정 없이 MCP 기본값(현재 LM Studio에 로드된 모델)을 사용한다.
- [Rule 6] 로컬 모델이 응답한 결과는 에이전트가 검토·보정하여 최종 결과물을 만든다. 로컬 모델 응답을 그대로 전달하지 않는다.
- [Rule 7] 로컬 모델 위임이 불가능한 상황(MCP 연결 오류, 타임아웃 등)에서는 클라우드 모델로 자동 폴백하고, 사용자에게 해당 사실을 알린다.
