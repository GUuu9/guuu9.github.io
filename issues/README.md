# 진행 중인 내용·오류 메모

아직 완성하지 않은 가이드, 조사할 오류와 다음 작업 메모를 보관합니다. 검증된 사용 절차는 해당 Setup·Tools·Servers 문서에서 관리합니다.

- 이 README만 Git으로 관리하고 나머지 파일·하위 폴더는 `.gitignore`로 제외합니다. 로컬 메모는 커밋·push하지 않습니다.
- 주제별로 소문자 kebab-case 이름의 Markdown 파일을 만듭니다. 필요할 때 현재 상태·OS/도구 버전·증상/재현 방법·확인한 내용·다음 작업·참고 링크를 기록합니다. 해당하지 않는 항목은 생략합니다.
- 오류 로그에서 토큰·개인 키·개인정보를 제거합니다. Git 제외는 비밀정보 보관 수단이 아닙니다.
- 해결 후 검증된 내용만 적절한 정식 문서로 옮기고, 로컬 메모에 해결 여부를 남깁니다. 고유한 조사 내용은 임의로 삭제하지 않습니다.

다른 PC로 clone해도 로컬 메모는 복원되지 않으므로 필요한 자료는 별도로 백업합니다. 정식 문서에서 Git 제외된 개별 메모로 연결하지 않습니다.
