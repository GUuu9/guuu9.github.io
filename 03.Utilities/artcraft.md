# ArtCraft 앱

ArtCraft는 이미지 편집·벡터 그래픽·모션·영상 제작 앱을 제공하는 창작 도구 모음입니다. 앱별 기능과 지원 OS·CPU는 공식 앱 목록에서 확인합니다.

일반 사용은 [ArtCraft Apps](https://getartcraft.com/apps)에서 **Download Launcher**를 선택해 런처를 설치한 뒤 필요한 앱을 내려받아 실행합니다. 런처와 앱 업데이트도 해당 경로를 이용합니다. 일반 사용에는 Rust·Git 설치나 소스 빌드가 필요하지 않습니다.

소스 저장소와 프로젝트별 개발 안내는 [ArtCraft GitHub 조직](https://github.com/storytold)을 확인합니다.
