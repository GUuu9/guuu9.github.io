# ChatGPT

ChatGPT는 질문·학습·글쓰기·자료 정리·이미지 생성 등 일상 작업을 돕는 AI 서비스입니다. 코딩 작업에는 Codex를 사용할 수 있습니다.

| 사용 방식 | 공식 링크 |
| :--- | :--- |
| 웹에서 사용 | [chatgpt.com](https://chatgpt.com/) |
| 데스크톱 앱·모바일 앱 다운로드 | [ChatGPT 다운로드](https://chatgpt.com/download/) |
| 기능·용도 확인 | [ChatGPT 소개](https://chatgpt.com/overview/) |

앱은 공식 다운로드 페이지에서 운영체제에 맞는 설치 파일을 선택합니다. 로그인과 사용 가능한 기능·요금제는 공식 페이지에서 확인합니다.
